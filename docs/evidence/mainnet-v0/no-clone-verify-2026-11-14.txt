No-clone verify of the mainnet vault v0.probarion.near with probarion 0.1.1 from npm (2026-11-14, UTC+7)

What this records
-----------------
The site serves the mainnet vault's signed ledger, and the files verify reads beside it, under
https://probarion.xyz/samples/mainnet/ (apps/web/public/samples/mainnet in the repository):

  ledger.jsonl                     docs/evidence/mainnet-v0/s2-2026-11-13/ledger-2026-11-13.jsonl (6 entries, after S2)
  mainnet-proof.json               docs/mainnet-proof.json (the recorded transactions; --proof reads its burn tx hints)
  evidence/v0-decision-m001.json   docs/evidence/v0-decision-m001.json (spend 1's pre-ledger decision, for check d)
  invoices/invoice-INV-M002.txt    docs/evidence/mainnet-v0/s1-2026-11-13/invoice-INV-M002.txt (A8, entries 0 and 1)
  invoices/invoice-INV-M003.txt    docs/evidence/mainnet-v0/s2-2026-11-13/invoice-INV-M003.txt (A8, entry 4)

Each one is a byte-for-byte copy of the file on its right; apps/web/test/samples-mainnet.test.ts compares them.
The blocks below download the first three into an empty folder and run `npx -y probarion@0.1.1 verify` on mainnet,
with no clone and no key. Verify reads the chain with read-only RPC requests (views, and tx lookups of the burn
transactions). It signs nothing and sends no transaction.

probarion.xyz did not serve these files yet when these runs were made, so the runs fetched
the same bytes from two other places:
  runs 1 and 2: a local HTTP server on 127.0.0.1:4802 serving apps/web/public of the branch feat/mainnet-samples,
                at the exact paths the site serves;
  runs 3 and 4: raw.githubusercontent.com at f35f9e0 (origin/dev), from the source files in docs/ (run 3 prints their
                sha256, the same as the served copies').
Run 5 is the repository's CLI on the served copies, with the two invoice texts.

Machine: Windows 10 Pro 10.0.19045, Node v24.12.0, npm 11.6.2. Git Bash 5.2.12 with curl 7.87.0, and Windows
PowerShell 5.1.19041.6456 with curl.exe 8.13.0. This machine has no Node 22. .github/workflows/no-clone-verify.yml
is set to run the Bash block on Node 22 and Node 24 for every pull request and every push to dev and main; its
first result is not recorded here yet.
Each run's first line gives its time in UTC (2026-11-13, 19:02 to 19:11 UTC). Program output is verbatim.

Result
------
Runs 1 to 4: checks a to h PASS and check i SKIP (no factory made the vault), "8 passed, 0 failed, 0 unproven,
1 skipped", "RESULT: PASS", exit code 0. That is what scripts/judge.mjs expects of this vault (LIVE_VAULTS.mainnetV0),
with one difference in check e's reason: probarion 0.1.1 has no --invoice flag, so A8 does not run ("A8 not run");
A1 to A7 pass on the 3 attested decisions. Run 5, the repository's CLI given the two served invoice texts, matches
LIVE_VAULTS.mainnetV0 exactly: A8 passes for 3 of 3 attested decisions (seq 0, 1, 4).

Caveats: without --online, check e does not verify the TEE quotes (O1, O2), and the TEE measurement is not pinned.
The mainnet payments so far are tests to the owner's own addresses. The code is unaudited.

The PowerShell block calls npx.cmd: Windows PowerShell 5.1 resolves plain npx to npx.ps1, which a Restricted
execution policy refuses to run.
